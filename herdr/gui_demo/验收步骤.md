# GUI demo 验收步骤

> demo 的用途、部署和代码结构见同目录的 `README.md`;方案与全部实施、审核、交叉验证记录见 `../claude/21-gui-demo-plan.md`。

## 0. 准备

验收实例跑在 OrbStack 的 Ubuntu VM 上:`~/gui_demo_run`,默认数据目录 `~/.a2a_gui_demo`,端口 8765。

1. **确认后端在运行**(Mac 终端):

   ```bash
   curl -s -o /dev/null -w "%{http_code}\n" http://192.168.139.41:8765/
   ```

   返回 `200` 就是在运行。不是 200 的话,在 VM 上启动:

   ```bash
   orb -m ubuntu bash -lc '~/gui_demo_run/bin/start'
   ```

   它会打印一个登录地址,直接用这个地址做第 2 步。

2. **取登录地址**(登录地址只能用一次;换浏览器、用过了、后端重启过,都要重新取):

   ```bash
   orb -m ubuntu bash -lc '~/gui_demo_run/bin/login-url'
   ```

   打印的地址形如 `http://192.168.139.41:8765/#token=…`。

3. **在自己的 Chrome 里打开这个地址**。之后在同一个浏览器里刷新,仍然是登录状态。

说明:

- 要用 IP 访问。这台 Mac 上 `ubuntu.orb.local` 会被代理软件解析成 198.18.x.x,打不开。
- VM 的 IP 是自动分配的,VM 重启后可能变;`bin/start` 打印的是实际地址。

## 1. 页面一:工程列表

- [ ] 点"+ 新建项目",填工程名称(比如 `SoC-A`)。项目路径会按名称自动填成 `/home/jhx/projects/<名称>`,可以改;简介可不填。点"创建",约 5 秒后出现新卡片,显示"运行中"。
- [ ] 卡片上有名称、简介(没填时显示"还没有简介")、项目路径、运行状态、"进入"。

## 2. 页面二:智能体页

- [ ] 点工程卡片进入。左边是"验证智能体 / 软件智能体",右边是当前这一类的 agent。
- [ ] 在"验证智能体"下点"+ 新增 IP",输入 `uart`,点"新增"。约 10 秒后出现 `dv_uart` 卡片,下面是真实的 fnx_dv 终端。
- [ ] 切到"软件智能体",同样新增 `uart`,出现 `sw_uart`(fnx_sw)。左边的数量随之更新。
- [ ] 同一 IP 下另一类也在时,删除按钮显示"删除整个 IP";只有一类时显示"删除"。

## 3. 终端

- [ ] 在终端里可以看到 fnx 界面,可以打字。

> ⚠️ **在终端里按回车会把输入提交给 fnx,会调用模型。** 只想看看的话,打完字用退格删掉,不要按回车。新增 IP 启动 fnx 本身不会调用模型。

- [ ] 改浏览器窗口大小,终端会跟着重新排版。
- [ ] 可以在另一个标签页里打开同一个工程,两边看到的是同一个终端,互不挤掉。

## 4. 停止 / 重启

- [ ] 点卡片上的"停止":状态变成"已停止",终端变灰、只读,底部提示"agent 没在运行,终端只读"。终端里会露出 pane 自己的 shell 提示符,这时输入会被拦住。
- [ ] 点"重启":约 10 秒后 agent 在原来的 pane 里重新起来,终端恢复可输入,不用刷新页面。

## 5. 删除

- [ ] 点"删除整个 IP":确认框会列出要一起删掉的 `dv_uart`、`sw_uart`。确认后两张卡片都消失。
- [ ] 回到工程列表,点工程卡片右上角的"删除":确认框会写明删除哪些东西,以及**不删**项目路径。确认后卡片消失。

## 6. 恢复(可选,模拟 VM / herdr 重启)

1. 先建一个工程,并新增一个 IP。
2. 在 Mac 终端停掉这个工程的 herdr 会话。会话名在页面二标题下方,形如 `guidemo_p…`:

   ```bash
   orb -m ubuntu bash -c 'herdr session stop <会话名>'
   ```

- [ ] 回到工程列表(刷新一下),卡片显示"herdr 会话未运行"和"恢复"按钮。
- [ ] 点"恢复",约 10–20 秒后变回"运行中"。进入页面二,agent 回来了,终端正常显示。

## 7. 登录地址(只有我一方验证过的一项,请顺手确认)

- [ ] 在另一个浏览器(或无痕窗口)打开 `http://192.168.139.41:8765/`,显示"未登录"页。
- [ ] 在 Mac 终端运行 `orb -m ubuntu bash -lc '~/gui_demo_run/bin/login-url'`,把打印的新地址**粘进同一个标签页**,应直接进入工程列表。

## 8. 验收之后

- 停止后端(herdr 会话和 agent 保留,下次 `bin/start` 后继续可用):

  ```bash
  orb -m ubuntu bash -lc '~/gui_demo_run/bin/stop'
  ```

- 要彻底清掉验收时建的东西:先在页面上把工程都删掉,再停止后端。删除工程不会删项目路径,需要的话手动删 VM 上的 `~/projects/<名称>`。
- 已知限制见 `../claude/21-gui-demo-plan.md` §8。主要几条:
  - 不支持单独删除一类智能体;
  - 从外部用 a2a 命令行停止 agent 时,终端约 2 秒后才变只读;
  - 没有账号登录和多用户。
